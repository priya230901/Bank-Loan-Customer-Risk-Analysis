# Bank-Loan-Customer-Risk-Analysis
# Project Overview
Banks generate a large amount of customer and loan-related data, including customer details, loan types, loan amounts, income, credit scores, risk categories, and repayment information. Managing and analyzing this data manually can be time-consuming and may lead to errors.
The Bank Loan & Customer Risk Analysis Dashboard is a Power BI project designed to analyze banking and loan data efficiently. It provides meaningful insights into loan performance, customer segments, risk exposure, outstanding balances, and default rates to support better decision-making and risk management.

# Objectives
Analyze the overall loan portfolio and outstanding balance.
Monitor loan status and default rates.
Identify high-risk customer segments.
Analyze loans based on type, income, age, and customer segments.
Compare loan performance across different states/branches.
Provide actionable insights for better risk management.

# Dashboard Pages
1. Banking Dashboard
- Total Loan Portfolio
- Outstanding Balance
- Total Customers
- Active Loans
- Default Rate
- Monthly Loan Trends
- Loan Status Analysis
- Customer Segmentation
- Income & Age Analysis
- Loan Type Analysis

2. Risk Analysis
- Loan Portfolio by Risk Category
- Outstanding Balance by State
- Default Rate by Loan Type
- Default Rate by Occupation
- Risk Category Analysis
- High-Risk Customer Identification

3. Insights & Recommendations
The project also highlights key business insights and recommendations, such as:
- High-value customers contribute significantly to the portfolio.
- Home loans form a major portion of lending.
- Personal loans show higher default risk.
- High-risk customers represent significant exposure.
- Loan portfolio diversification can help reduce risk.
